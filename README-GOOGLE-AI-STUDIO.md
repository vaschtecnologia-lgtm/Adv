# Google AI Studio Multimodal Web Starter

Este é um projeto simples e elegante para testar e interagir com os modelos de Inteligência Artificial **Gemini** (como Gemini 2.5 Flash e Gemini 2.5 Pro) diretamente pelo navegador utilizando a API do Google AI Studio.

## Recursos
- **Leitura Multimodal**: Envie imagens ou documentos de texto juntamente com seu prompt.
- **Seleção de Modelos**: Alterne de forma flexível entre os modelos disponíveis.
- **Armazenamento Seguro da Chave de API**: Sua Chave de API do Gemini é armazenada com segurança de forma local no navegador (`localStorage`), sem tráfego por servidores intermediários inseguros.
- **Renderização Fluida**: Resposta formatada para leitura agradável.

## Como Executar
1. Abra o arquivo `index.html` em qualquer navegador moderno.
2. Insira sua **Chave de API do Gemini** (obtida gratuitamente em [Google AI Studio](https://aistudio.google.com)).
3. Digite um prompt, opcionalmente envie um arquivo e clique em **Gerar Resposta**.
